# 轻练 H5

今天、计划、我的三个页面。标准动作库、计划处方和实际记录分开；28天阶段按7天周期展开。

访问：https://teacher-yang307.github.io/qinglian-fitness/

## 使用与数据

新用户填写年龄、身高体重、目标、运动基础、器械、可训练日期和时间。连续跑步公里数可选填。可选 DeepSeek 或本机规则，先预览再确认；没有虚构完成记录。

首个周期确认后，后三周期显示待生成。每周期填写身体反馈，再生成下一周期预览。确认只更新目标周期，已有实际记录和活动计时会阻止覆盖。旧计划继续读取原版动作内容，旧阶段也可调整没有训练记录的未来周期。

个人数据仅保存在当前浏览器的 LocalStorage，不跨设备自动同步。请在“我的 → 本机数据与备份”导出 JSON；备份包含个人资料、计划、实际记录及动作定义快照。换设备后导入并检查确认。清理站点数据或关闭无痕窗口前请备份。

“我的 → 训练计划管理”可重置计划和进度，保留个人资料，重置前保存一份可恢复副本。首次把旧阶段未来周期接入新版前另存升级备份，可在备份卡恢复；恢复会替换当前数据。密钥、邀请码不进入个人备份。

## 统一动作库与计量

`library/exercise-library.json` 是发布时锁定的标准库，当前2.2.0，共62项。源于工作区 exercise-library-pack；更新母版后复制主库，并运行 `node scripts/sync-library.mjs --import-assets` 导入新增资产。不要分别手工修改生成数据、提示词和校验。

构建时从主库生成 `src/library-data.mjs`；浏览器与 Cloudflare 共享 `src/catalog.mjs`、`src/ai-plan.mjs`。固定名称、步骤、适用场景、计量方式和图片通过编号读取，模型不能改写。不同版本的定义存入计划的 librarySnapshots，历史任务通过自己的 libraryVersion 还原。

计量包括组次、保持秒数、持续秒数、间歇段和公里。跑步 easy_run 按公里为目标；预计耗时独立提供。完成记录中的实际组次、距离和时间独立保存，快捷打卡不会自动填写计划值。实际时长未知时保持未知，不按计划分钟、公里或次数推算消耗和减脂公斤数。

## DeepSeek 服务

前端公开地址在 `web/ai-config.mjs`。后端为 Cloudflare Worker，入口 `cloud/worker.mjs`；`DEEPSEEK_API_KEY` 和 `GENERATION_ACCESS_CODE` 保存在 Cloudflare Secret，绝不放入前端、仓库或发布日志。站点邀请码保留，每日生成次数和请求间隔限制保持关闭；旧 Durable Object 类仅为部署迁移兼容，不参与生成。

用户同意后仅发送必要个人资料；周调整另发送已同意的难度与恢复枚举、完成项数、已记录时长和距离摘要。姓名、联系方式、自由备注、训练描述及逐项历史记录不发送。后端不打印请求正文和模型原文。

结果通过动作、场景、计量、日期、顺序与时长校验后才返回预览。不合格时携带具体错误修正，最多尝试4次；网络和临时服务错误退避重试，密钥、余额及配置错误立即返回。最长等待约3分钟，可取消；失败不写入正式数据。旧页面与动作库版本不匹配时提示刷新，避免混用规则。

计划和插图为自主训练参考，未经过独立专业审核。结构校验和模型返回不等同于专业审核；本机记录可由设备使用者修改，不构成独立审计。餐饮建议仍需自行核对过敏原与适用性。

## 开发与发布

需要 Node.js 24；前端无第三方运行时依赖，Cloudflare部署使用Wrangler。

```sh
npm test
npm run build
python3 -m http.server 4175 --directory docs
```

GitHub Pages 使用 main 分支的 /docs。修改源码后构建并提交源码与 docs/。构建为模块生成同一个缓存版本；静态内容不包含个人记录。后端发布使用 `pnpm exec wrangler deploy --keep-vars`，保留已有密钥、日志与预览设置。后端和前端需要使用同版协议与动作库。

本机浏览器通过 `src/local-store.mjs` 调用共用领域逻辑。`worker/api.mjs` 中的历史服务端API保留用于旧版兼容与测试；本H5运行时不连接旧登录数据库或OpenAI生成分支。当前模型调用仅走独立Cloudflare的DeepSeek接口。

维护模块关系见 [ARCHITECTURE.md](ARCHITECTURE.md)。`diagnostics.html` 使用固定虚构资料自测，不读写个人记录；检查连接只查询模型列表。
