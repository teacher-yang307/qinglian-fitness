# 轻练 H5

三个页面：今天、计划、我的。28 天居家训练参考阶段，每 7 天反馈一次；逐项打卡、实际计时、动作讲解、餐饮建议、周期进度。

## 使用

访问 https://teacher-yang307.github.io/qinglian-fitness/ 。新用户首先看到资料引导，填写个人信息、目标、器械、可训练日期与时间后启用自己的 28 天规则参考计划。选填项可以留空，校验错误直接显示在表单内。本站不会预填任何真实用户的健康资料。无 AI API、无账号登录、无云端数据库。

所有记录只保存在当前浏览器当前站点的 LocalStorage，不跨设备同步。清除站点数据、无痕窗口关闭或换浏览器可能导致记录不可用。请在“我的 → 本机数据与备份”定期导出 JSON；换设备后选择导入，检查确认后恢复。备份含个人资料和训练记录，请妥善保管。旧 Sites 站点数据不会自动迁移到此域名。

## 开发与发布

需要 Node.js 24，无第三方依赖。

```
npm test
npm run build
python3 -m http.server 4175 --directory docs
```

源代码位于 web/、src/、worker/（共用训练校验，浏览器本地执行）。docs/ 为可发布静态产物，资源路径支持仓库子目录。

GitHub Settings → Pages → Deploy from a branch → main /docs。修改源码后重新构建并提交 docs/，GitHub 自动部署。不要提交 .env、数据库、个人备份或密钥。

打卡不自动填写实际时长。计时记录只代表计时过程；本地记录与修改历史可被设备使用者修改，不构成独立审计。训练内容为一般健康成年人的自主训练参考，未经过独立专业审核，图片仅说明动作要点；不以训练时长承诺减脂公斤数。
